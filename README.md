# 霜藍週報｜Gemini 訪談測試版

這是**測試版，不是正式版**。預設連接「ATM 任務追蹤系統資料庫－週報測試副本」，不會修改原始正式試算表。尚未在實際 GitHub Pages 網址完成真人 Google 登入或 Gemini 全流程驗收；請先用副本測試。

測試副本：https://docs.google.com/spreadsheets/d/1qQPtVhl2lmQyu_AHvfY-s6i2vst2DgENL6pMwc7JeRo/edit

副本複製了原系統資料，請先檢查其 Google 雲端硬碟共用權限，確保只分享給允許存取的人。網站只讀取副本的「案件總表」及「子項目清單」，新增或修改僅寫入副本內的「週報_專案」、「週報_紀錄」、「週報_歷史」。

## 部署或更新

1. 解壓縮，將所有檔案上傳至獨立 GitHub 儲存庫的根目錄；若已上傳過上一版，以本版所有檔案更新，**不要漏掉新增的 `interview.js`**。不需上傳個人機密、測試檔或任何試算表資料。
2. GitHub 儲存庫的 Settings → Pages 選擇 Deploy from a branch，選 `main`（或實際分支）及 `/ (root)` 並儲存。等 Pages 完成，使用 HTTPS 網址開啟。
3. 使用與原雜事系統相同的網域 `https://pppxd828-dotcom.github.io`；路徑由新儲存庫名稱決定。不要用直接雙擊 `index.html` 的方式測試 Google 登入。
4. `config.js` 沿用原系統 OAuth client ID、指向測試副本。Google Cloud OAuth 網頁應用程式的授權 JavaScript 來源須包含上述網域；如果 OAuth 同意畫面處於測試狀態，帳號也需是允許的測試使用者。若登入失敗，檢查設定，不要關閉安全措施。
5. GitHub Pages 的程式碼可能公開。Sheet ID 與 OAuth client ID 為識別碼，不是密碼；試算表存取權限仍須妥善設定。不要把 Google 密碼、OAuth client secret 或 API key 放入儲存庫。

## Gemini 訪談操作

1. Google 登入後，到「專案管理」核對專案、需求號、預設處理人與里程碑。新時程精度可為 `116年6月` 或 `116年6月15日`，不要為未知日期自行補日。
2. 選「Gemini 訪談」，選所需週次中的任一天；網站自動計算週四至週三。預設為本週，過去的週次也可選。頁首的大型橫幅仍顯示**本週**，訪談面板內的週次才是這次選定範圍。
3. 網頁自動唯讀載入雜事候選。現行週次預設包含未結案及所選週有更新的已結案案件；取消勾選不想帶入的案件，不影響原系統。保留的案件會帶入全部子項目、所選週可辨識日期的歷程。已存在的所選週工作紀錄也會帶入。即使沒有任何紀錄和候選雜事，仍可訪談。
4. 點「產生訪談 Prompt」檢查內容，確認符合你的資料使用規範後再複製到 Gemini。Prompt 會包含專案、工作紀錄、案件及子項目資料；網頁不會自動把資料送給 Gemini，也不會自行連到 AI。
5. Gemini 應逐案、一次一題訪談，請你確認案件歸屬、必要的進度與影響；先列建議列入及不列入的摘要，經你確認後直接產出週報。若支援產檔，要求 Word；否則提供可複製的兩欄表格。Gemini 的實際表現與 Word 產檔能力取決於服務，請自行核對內容。
6. 來不及寫完時，回到同一段 Gemini 對話繼續。**對話與產生的 Word 不會自動保存到網站或 Sheet**。

### 舊週候選的限制

補寫舊週時，網站保守列出建立日期不晚於週末的案件，即使它後來才結案；這可能包含當週早已結案的案件，請手動移除。建立日期不明的案件亦會列出。來源缺少完整狀態歷史時，無法保證清單完整或自動還原當時狀態；目前狀態、子項目狀態及專案目前時程都只是現在的快照，應由你向 Gemini 確認當週事實。無法辨識日期的歷程不會帶入，網頁會標示並提醒確認。

## 選用：把訪談紀錄備份回網頁

在 Gemini 對話中要求「請產生訪談備份 JSON」，只需新增或修正的工作紀錄。回到「Gemini 訪談」點「貼上訪談備份」，貼上 Gemini 的 JSON：

- 在確認畫面核對、編輯並勾選紀錄後才儲存；新增紀錄預設未勾選週報，修改既有紀錄會保留原勾選狀態。
- 修改紀錄必須保留 Prompt 中原有的紀錄 ID 與版本。找不到原紀錄或版本變更時會停止，請重新讀取及確認；請不要將修改偽裝成新增。
- 與現有紀錄完全重複的新增紀錄會跳過。備份只保留工作紀錄，不保存完整週報。
- 如備份包含時程提案，儲存後會另顯示確認畫面；只有你勾選並確認才會更新專案主檔。未貼回備份時，專案時程維持原狀。
- 若同批修改已寫入但後續新增失敗，畫面會特別提示。請重新讀取核對結果後再處理，不要盲目重試。

原本「工作紀錄」貼上一般 JSON、直接讀取雜事與 ATM Excel，以及舊版「產生週報」流程仍可使用。舊版「產生週報」及「歷史紀錄」只處理其原本的當週勾選資料與 Prompt；**Gemini 訪談產出的 Word 不會自動進入那裡**。

## 隱私與限制

- Google 登入要求 `spreadsheets` 權限，此權限涵蓋該帳號可存取的試算表，不僅一份；請確認後才授權。權杖只留在目前網頁記憶體，重新開啟或過期可能須再次登入。
- 請一次只在一個分頁或裝置修改；版本檢查可降低覆寫風險，但無法提供 Google Sheets 多裝置的完整交易鎖。網路錯誤後請重新讀取核對再重試。
- Google Sheets 可能保留版本歷史；清除資料不保證從所有歷史版本永久抹除。Prompt 如包含敏感資訊，使用第三方 AI 前請先確認規範與可分享範圍。
- 訪談 Prompt 是文字指令，不是已驗證的 AI 模型或自動代理。Gemini 可能忽略要求、誤判分類或虛構事實，必須人工檢查；使用者沒有確認的歸屬、影響與日期不能視為事實。
- 本版尚未正式驗收；先不要把 `config.js` 指向正式 Sheet。正式切換前須另行備份、建立專用工作表並完成驗證。
